CustomerId
Gender
Age
Tenure
Usage Frequency
Support Calls
Subscription Type
Total Spend
📈 Analysis Performed
Churn distribution analysis
Gender vs Churn
Subscription Type vs Churn
Support Calls impact
✅ Conclusion:
Customers with more support calls are likely to churn
